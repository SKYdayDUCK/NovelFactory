# 身份与敏感数据边界

| 主体 | 受权操作 | 独立验证 |
|---|---|---|
| 作者、Workshop 管理者 | 组织的名册、费用和历史；发送有幂等键的项目恢复意图 | live binding、组织任期、安装、当前角色；NF resume 使用单独签发的作品/分支授权 |
| 编剧、导演、卷纲、演员 | 当前任期可见的名册、允许方向和类型的组织消息、本人收件箱、任务范围内 Skill | 联系图版本、TTL、发送/接收任期、临时授权剩余次数；NF BELIEF 仍需 actor、StoryPoint、WorldRef、任务代际和实时 Grant |
| 独立审核者 | 对明确分配的冻结版本提供组织意见 | 绑定生产者及其代理身份组，当前 reviewer 与任期、轮次、截止、证据和预算；领域批准交 NF |
| Workshop 对账进程 | SQL Hold、发送或查回已授权槽、审计回执、核对原 attempt | 私有安装绑定、原 operation_id、fence 和最新预算；模型与角色不可选程序路径 |
| NF 委托服务 | 预置槽对应的一次任务与 Supervisor 注册、当前任务与费用摘要 | NF 实例/作品/分支、角色、scope、grant epoch、generation、可信输入与预算 |
| 运维身份 | 建立服务和额度、冻结外发、还原备份、部署服务 | 受信 OS 身份、独立 DB 登录；操作员保管私有配置和外部部署记录 |

威胁模型包含冒充 sender、越级 ASSIGN、跨角色资料读取、使用过期授权、越权加载 Skill、在途撤权、丢回复后重复派工、成本 UNKNOWN、双数据库恢复点错位、历史被回写。原始角色材料和组织私信禁止进入管理历史或通用日志。审计持久化授权引用、版本、摘要、状态与来源。若受信运维身份或宿主进程已被完全控制，必须重新签发凭据并核对账本。目录/文档/自然语言提示本身不具备 NF 授权效果。
