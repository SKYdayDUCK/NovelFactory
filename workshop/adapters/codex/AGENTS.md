# Author entry point

When the author says “继续未完成的任务” in a Workshop project, discover the installed Workshop MCP tools. Read aw_state_get. Call aw_resume_project once with a stable operation_id for this author request, retaining that key if the transport reconnects. Report its request_id, state, pending review or budget blocker. A PENDING receipt is persisted. End the model turn; the local broker runs the bounded manager worker. Do not start another model turn merely to poll, and do not forward private organization mail into a fictional actor's knowledge.
