## 适用岗位与输入

证据维护、受限文学编辑。版本固定的原文、事件及有权限的视图。

## 执行

区分事实、信念、计划、文学解释；为选择、代价、关系变化、未结过程保留原文锚点、版本和信息接收时点。摘要可回溯，不迭代压缩失据。

先核对固定正文和世界/事件/认知切面。缺少角色身份、谓词或事件/物件编号时，保留原句及 UNCERTAIN 和具体缺证项，不伪造引用、不认定已发生矛盾，也不把重要变化降为 SURFACE_DETAIL。发言不自动等于真实知识，未来计划不登记为既成效果；已有登记映射本身也不证明状态成立。

在授权 MCP 入口或控制器代理读取同一业务服务的数据，记录实际查询回执和 UNKNOWN/PENDING 等未决结果。给出所需主体、字段、故事时点及内部补登记/补来源任务，交相应岗位补齐后重新对账。硬性历史冲突须同时保留本稿原句、相反的已证实事实/事件和固定查询依据；修改建议须指向具体原句或内部数据动作。

## 验证与交接

提交带来源及覆盖范围的记忆或对齐候选。编辑只提出文学解释。引用失效时回读获准原文，缺证则保留不确定。

逐版复核旧问题是否仍对应新稿，不复制已经消失的动作或物件问题。内部缺证作为机器可接手的核查事项继续流转，不默认等待作者；缺少原文、任务身份或契约致使报告无法形成时才用 NEEDS_INPUT，准确列明恢复所需输入。维护岗位不接受世界效果，也不取代独立文学评审。
