# Domain 局部规范

本文件继承 [根规范](../../../AGENTS.md)，仅约束本目录。

- 领域对象只接收显式参数，时间、随机性、版本和规则集由调用者提供。
- 禁止导入 ORM、SQL、HTTP、MCP、外部模型、文件系统或全局 Session。
- 区分世界事实、角色认知、读者信息、计划、模拟和文学解释；不以缺字段代替语义状态。
- 世界版本与故事时间采用不同类型；跨分支版本不能比较数值大小来推断先后。
- 行动建议和裁决候选不直接应用效果；正式接受由应用服务管理。
- 效果、前置条件及相关资源必须可供外层审计、去重和并发控制。
- 重放既有事件不得再次调用模型；规则版本及解释器版本须能定位。
- 文学表达保留自由度，领域硬规则只约束资源、权限、状态和接受边界。
- 新规则优先补边界反例；涉及共享资源的数据库竞争交给集成测试验证。
- 普通修复可自主完成；语义变化附 ADR 候选及兼容性说明，不要求所有领域修改都询问用户。

- 统一故事坐标不合并计划与事实；已解析关系效力与模糊发生时间分开。注册命令模板声明必需读写/负向/约束scope，缺证明不得宣称可独立接受。

参考：[03 数据](../../../docs/03_数据模型与知识图谱.md)、[04 版本](../../../docs/04_事件溯源与版本体系.md)、[05 调度](../../../docs/05_世界模拟与调度引擎.md)。
