# Infrastructure 局部规范

本文件继承 [根规范](../../../AGENTS.md)，仅实现应用端口和资源生命周期。

- PostgreSQL 权威写入由应用用例事务控制；检索、缓存和图谱投影不是第二事实源。
- SQL 使用绑定参数；每线程/异步任务独立 Session，并明确关闭、提交和回滚。
- 生产并发语义在真实 PostgreSQL 验证；`SKIP LOCKED` 只用于队列领取等允许跳过的用例。
- 对象内容不可变，以哈希校验；对象先持久化再被数据库引用，孤儿回收需宽限期及引用检查。
- outbox/inbox 按至少一次交付设计，重复执行由业务幂等与效果约束吸收。
- 外部模型调用记录请求身份、模型/提示版本、预算和结果状态，丢回执保持未知并对账。
- 指标和日志避免输出秘密及越权上下文；保留定位任务、版本和提交的关联 ID。
- 投影重建使用新 generation 并核验后切换，不覆盖正在服务的已知有效结果。
- 备份核验必须覆盖数据库、对象哈希清单和解释器/配置版本；启动成功不等于恢复成功。
- 默认不新增独立数据库或常驻队列服务；先说明现有 PostgreSQL 方案的可测瓶颈。

- 多进程连接池按总实例预算；模型等待不占连接。scope创建/删除保留注册与tombstone守卫；缓存和副本不得绕过权限epoch及源水位。
