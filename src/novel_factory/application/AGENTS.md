# Application 局部规范

本文件继承 [根规范](../../../AGENTS.md)，用例是领域写入的唯一入口。

- 先校验可信 Principal、作品/分支范围、角色能力和输入契约，再调用领域逻辑。
- actor 由授权绑定，不能相信请求 JSON 自报的身份；查询和错误响应同样过滤权限。
- 每个用例定义输入、返回收据、幂等范围、预期版本、事务边界和稳定错误码。
- 业务计算及模型调用在事务外完成；正式接受在短事务中重新校验版本、前置条件和审批。
- 世界接受同时提交事件、关键投影、推进进度、最小失效记录和 outbox。
- 显式区分世界接受、正文接受、本地发布与外部交付，不能复用一个模糊的 commit。
- 通过端口调用存储、对象、模型和检索；不要把 SQL 或 Host 细节泄漏到领域层。
- 重试必须保留业务幂等身份；未知的外部结果先对账，不能默认未执行。
- 多任务写入用 head CAS、锁及约束兜底；不把过期候选静默改基后提交。
- 服务返回权限过滤后的结果与证据引用；缓存不得绕过版本和角色范围。
- 对故障注入测试验证事务要么完整接受、要么不接受，并覆盖丢回执后的重试。

- R1守卫提交复验完整证书binding、base≤validated≤parent同枝血缘、当前授权/解释版本及scope；批量读先固定cut，不能逐项解析latest。
