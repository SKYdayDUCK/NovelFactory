# 文风审稿与返工交接

**输入**为本任务已授权的正文版本、题材与读者、可见叙事视角及适用的相邻正文。若只拿到一个片段，意见限于片段。整卷结论需要通读每章原文，并标明起讫和阅读版本。工具、写入权限和可见世界事实均依现有任务契约。

1. **首遍挂起模型标签。** 连续阅读，标出第一次跳读、被旁白说破、无法辨认说话者或愿意停下来重读的地方。记“第三章，‘炉门还开着’后第二段”，勿只写“辞藻华丽”。至少留下一处应保留的原文长处，允许全章没有需改项。
2. **复查是否成了模式。** 取同稿同类单元作参照。说话人、视角、出现位置、是否新增事实或情绪，各记一笔。若称“跨章反复”，至少举出分处不同章的原文短锚；若谈密度，要给分母，如“抽查的六个章末有四个用旁白点题，第六章用反讽反转”。这只是覆盖范围，无触发扣分的频率阈值。一次泄露核心谜底本身就可成为重要意见。
3. **找合理解释。** 这是否是职业术语、核心母题、人物自欺、民间复沓、哀悼仪式或喜剧回环？在同稿举一个应保留的对照，或说明为何比不了。例如商贩查账有实际用途；父亲和孩子都称告别是“还债”，却可能来自家中常听的一句旧话。
4. **决定谁处理。** 情节或认识范围真出错，交已有连续性/认知审核，并向文学编辑说明对悬念的影响。纯措辞、声音和节奏由文学编辑合并成一项；写作者只接收一份有优先级的修订单。归因证据不足时记录观察，保留原文。
5. **用最小改动复读。** 先删一句、交换两句或保留原稿作对读。影响整卷时先在一处验证，再检查前后呼应。写作者可拒绝建议，解释这处形式在正文里的作用。由负责编审的已有角色闭合一次复读，不启动新的岗位或额外审级；本实验最多两轮，遵守作品总流程的停止条件。

| 优先级 | 证据门槛 | 处理与退出 |
|---|---|---|
| 必修 | 已给出证据，重复或解释明显破坏关键转折、人物行为依据或大段阅读连贯性 | 指定一个负责人、一段或一个场景范围；完成后直接核对原始损害是否消除。作者身份推测不能成为否决理由。 |
| 建议 | 已有可定位影响，仍有体裁或声音上的合理选择 | 编辑提出一个可试操作和要保住的作用；若改动成本超过可见收益，接受保留并记缘由。 |
| 观察／保留 | 孤立词例、猜测、明确有效的母题，或只掌握片段却想泛论全书 | 不开返工；有新正文证据时才重启。 |

不得把查词命中数、检测器概率、标点风格、模型签名、自称“人写”的标签用于判作者或替代质量分。跨章重点只有抽样时明确写“抽查”；最终独立质量评阅须另按冻结的标准阅读实际全文。外部证据和专题示例见[社区研究](../../research/literary_agents/COMMUNITY_AI_STYLE_RESEARCH.md)和[文风诊断](AI_WRITING_PATTERNS.md)。
