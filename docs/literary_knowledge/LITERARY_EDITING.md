# 通读、定位与有限修订

创作准备时声明这部作品希望哪类读者读到什么。审阅者先顺序通读实际正文，记下第一次开始期待、困惑、失去兴趣和重新投入的地方。留下章名与相邻原句。未读的范围标明未读。通读笔记可以朴素，例如“第四章她把小凳子还回去时，我才觉出前面三次让座的人一直在撒谎”。文笔好坏需要落到这样的阅读经历。

|编辑层次|何时介入|该交还什么|
|---|---|---|
|发展与结构|核心行动的动机不成立，卷中段重复，结尾靠新设定，首尾承诺错位|列出受影响的最少章节及一个可行处理方向。先确认有无刻意的反讽、空白或类型实验。|
|章节|两场提供相同信息，转场后无法辨认日期或视角，关键反应缺失|给出前后章引文和具体读者后果。可合并、移位或补一道反应；说明被保留的气息。|
|行文|同一解释多次覆盖动作，声线互换，句法盖住动作，突出的意象没有被使用|在一个代表段试改，保留作者可以拒绝或另解的空间。读出改前改后的节奏。|
|校对与事实|称谓漂移、前后手位不一、说话者提前知道未披露事件|区分排印错误、明确事实矛盾、人物自己的误认。前两项走既有修订路径，误认只在文本无法承载时建议补依据。|

## 如何写得出可以执行的一条审稿意见

原创例：第二章“他把箱底那封信折了三次”已让读者知道他读过信；第五章“今天我才第一次看到”可以是谎话。如果没有人因此采取不同选择，先问作者此处要表达谎言、误会还是日期错误。证实为谎言时可在第五章保留原句，让他仍习惯把纸折成同样的小方块。证实为日期错误时修两个章位的最小一处，复读所有受影响的知情者。新增细节若会泄露更晚的谜底，撤回试改。

格式可直接用一行：“章／原句 → 我由此作何判断 → 后文在哪推翻了判断 → 建议处理与预计损失”。相同根因只交一次给负责编辑。纯口味意见可以写成可选项。人物不可信、事实矛盾导致结局失效等影响广的意见优先，各自给出足够的证据。编辑先读完结构再润色可能删除的句子。

## 从修改到交稿

1. 确定这次修改究竟修什么，例如“让第五章的拒绝在已知人物利益中成立”。比较修改前后的原文，不用同义词替换数充当改善依据。
2. 复读发生变化的章、提供依据的前章、兑现后果的后章，并检查产生的新误读。整卷重排后还应按新次序顺读全文。没读全文就保留相应限制。
3. 段落顺畅、核心问题已有合理回应时即收手。同一处有两种成立的趣味，无须投票平均。冻结前记录尚存的分歧、作者的选择和证据位置。实验终评另由独立评阅者完成。
4. 交稿只写可核查的状态。手工定稿、协作修订、实际运行时冻结分别由其直接证据支持。文学编辑不能代替批准世界事实，也不能在评估阶段替独立评阅者改分。
