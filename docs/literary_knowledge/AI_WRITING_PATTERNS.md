# 常被读者称为“AI 味”的叙述问题

编辑在具体稿件上发现读者已经读懂、却被迫又读一遍，或几个人物的声音逐渐混在一起时，再查本页。它面向作品编辑；作者及模型身份不属于审稿结论。资料号均可在[社区研究与来源](../../research/literary_agents/COMMUNITY_AI_STYLE_RESEARCH.md)核对。样例为本项目原创，不能用作模型生成证据。每行只试一种最小改动。

| 读者会遇到什么／线索来源 | 原创样例与出现条件 | 审稿动作与修改办法 | 保留条件与误改代价 |
|---|---|---|---|
| 动作之后又附一份动机辩护（C2、C4） | “她把门闩插上。她并非不爱母亲，只是需要守住自己的边界。” 上一段她已将母亲的手从孩子肩上移走。 | 遮住第二句，问读者能否理解关门的对象及其代价。能理解就让门外的反应接上。 | 犹疑不可靠的第一人称可能正在给自己找借口。剪掉自辩会剪掉她的自欺。 |
| 否定、重定义、三项排比连续出现在不同声音里（C1、C2、C5、C9） | 每逢质疑，父亲、顾客、店员都回答“这不是钱，是体面”；随后旁白又重复一遍。 | 找三人说这话时各自实际要换得什么。保留一句最有身份与利害依据的，把另一句换成对方实行或拒绝的请求。 | 店员在柜台前重复统一话术、证人纠正听错的金额都合适。全删对称句会损失滑稽效果或事实精度。 |
| 同一副身体替所有人反应（C1、C4、C5） | 厨师听到停业、孙女看到通知、房东谈租约都“攥白指节、吸了口气”。 | 读当前场及相邻场，标记动作对物、对人、对时间有无后果。厨师若正在盛汤，可让他把第一碗端给平时排最后的人。 | 同一人的顽疾、暗号或变化中的手艺可以反复写；强行替换成新动作容易生出无依据的小道具。 |
| 对白过于自足，所有人都替听者分析感受（C4；亲疏地位测试属 H） | “我理解你想念她，也理解我害怕失去。” 两个互不相让的人轮流这样说，谈完无人作出决定。 | 拿掉姓名，读一轮谁在推谁作决定、谁能不答、谁说错话。保留一方善解人意，给另一方一次真实的打断、误听或拒答。 | 夫妻接受调解、医生告知家属等场合，耐心复述能缓冲羞辱。人人都用短句顶嘴也会同声同气。 |
| 情绪一律无比激烈，或一律“稳稳接住”（C1、C2、C5） | 午饭被取消和失去住处都以“天塌了”收尾。 | 对照两场各损失了什么。删去一处对强度的标注，写当事人今晚如何取回行李；另一处可保留玩笑般的夸张。 | 轻事重写有时正显出孩子或焦虑者的眼光。压低所有地方会消掉幽默、愤怒与戏剧冲击。 |
| 意象跨人物扩散，顶替案件、亲情、日常劳动（H；C5、C6 仅支持别的形象反复） | “哥哥欠我一个名字”“雨把旧债洗去”“厂门量着岁月的重量”。同卷先后用账、名字、棋子解释本应不同的损失。 | 将每次出现记成“谁看见／实际指什么／这次带来什么新理解”。先写清人物究竟错过哪一天、哪趟船。优先保留最有来源的一次。 | 失名者的证件、实物账簿、棋手的复盘，都有独立作用。删光职业语言或核心母题会损伤全书统一。 |
| 换词不换意思，描写借五感把同一判断说三遍（C2、C5；A1 专家评语） | “墙发冷，灯发冷，连告示上的字都冷。” 再下一段还在告诉读者屋子冷。 | 若第一处交代环境，问第二、三处的注意力是否移动。试把最后一次换成看错路标的结果，或删到能听出句子最后一拍。 | 反复也能形成歌谣、咒语或荒诞递进。删前朗读；无损事实仍可能伤及节律。 |
| 题材设定变成说明书，或人物突然知道章纲（C3、B2） | “潮闸每七年失灵一次，她马上明白自己就是被选中的人。” 作者前文仅让她听到警铃。 | 核对事实是否已建立、焦点人物在哪里得知、此刻是否需要解释。已有设定可延迟到她使用时；越权得知单列连续性意见。 | 面向新手的目击讲述可以解释基本规则。给“解释”换个隐晦说法不能修好知识来源。 |
| 场景开头重复点景，章末反复开谜或讲道理（C2、C5、C9、B2、A1） | 三章都从雾色起笔，以“门外响起了敲门声”结束，下章开门者与主线毫无关系。 | 对读三个接缝，逐个写出上章真正留下的事。一个接在上章付出的工钱，另一个落在新来者改变决定的时刻。 | 连载回环和民间讲述常有固定起结。若每次敲门改变同一家庭的地位，重复即有结构作用。 |
| 事件近义复演，角色或物件却无根据地漂移（C7、C8、A1） | 两章分别写“她把伞留给他”“她又把伞递过去”，期间没人归还，第二场没有新的分歧。 | 分开核查伞的位置和第二次递伞的作用。物件归属错交连续性审核；功能重复由编辑合场或改变后一场的选择。 | 第二次同一动作可能表示拒收变成愿收；不能合掉从礼貌变为和解的过程。 |
| 高潮跳过导致后来的行动失去重量（C6；B2 的首章节奏） | 十页铺垫两人争一张车票，一句“他们达成了协议”交代结果。 | 返回上次作出承诺的句子，让读者亲见必须放弃什么的一瞬；赶路和手续可概述。 | 有些作品故意留下夜里发生了什么，到尾声用证据重构。提前展开会毁掉叙述视角。 |
| 伏笔刚露面就被叙述者指认（C2、B1） | “那只缺角碟子将改变她的一生。” 正文随即三次提醒读者记住碟子。 | 在第一次和兑现处之间试删一次提醒，核对读者仍能凭此前公开的特征认出碟子。 | 戏曲报幕、宿命叙事可故意宣布结局。误删预告会丢掉“如何走到这一步”的期待。 |

同一个问题可影响多个评分维度。若多人对白重复解释动机，主要损失是声线时，落在人物或语言一项；若重复使读者提前知道凶手，交剧情审核处理信息释放。记录次要影响，避免对同一个段落开出两份重复改稿单。详见[审稿协议](AI_STYLE_REVIEW_PROTOCOL.md)。
