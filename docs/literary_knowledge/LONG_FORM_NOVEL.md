# 连载到后半部时还能写什么

卷导演在开卷、卷中停滞或卷末交接时读取。只在已有规划或交接产物中补充本卷用得到的证据。正文、既成世界事实、个人所知和导演期待各有不同用途；把后续可能性留在计划里，把已经发生的影响留给现有对账流程。

## 以一次真实改变承接下一卷

以原创故事“一家沿水路巡回的流动电影院”为例。全书开头许下的承诺是：姐弟两人能否把电影放回那个从未看全过最后一卷的村庄？第一卷可以只完成一件事——把船买下来。姐姐答应让一位老人终身免费搭船，因此冬天停航会使一位具体的人被困住。第二卷的事情从这个承诺长出来：弟弟想去能挣钱的大集，老人需要去医院。第三卷若只让他们再去更大的集市，规模变了，问题仍在原地。也可以让村民第一次拿到放映机，此后谁来选择放哪一卷，就不再由姐弟二人作主。

|节点|只为这一卷留下的内容|下一次能回查的地方|
|---|---|---|
|开头|读者眼下能盼到什么？谁在用什么可见行动使它成真？|开篇人物的动作或一句承诺，及其章节位置。私人愿望也可成为承诺。|
|开卷|卷内一件可辨认的成败；它与全书承诺的关系；已有哪件事使问题不可照旧解决|上卷最后一次选择的正文证据，哪些人物见证、哪些仍不知情。|
|卷中|写出两个原先可行、现在只剩一个的选择。若两个仍相同，看看是环境、人物目标还是双方关系还没动|造成变化的一次行为，谁从中取得议价能力或失去退路。|
|卷末|呈现兑现和它的余波。留给下一卷的可以是一项轮班义务、一处空位或一句再也说不出口的话|卷内实际发生什么，和原计划有何不同。只有需要下一卷记得的后果才列入交接。|
|收束|重看第一卷许下的读者承诺，让角色用其历史选择所剩的办法作答|并列读开头、最后决定和事后生活。若缺乏先行依据，回到早章检查或缩小结尾。|

## 支线、伏笔与群像

- 一条支线进场时，指出谁因它改变了原先计划。暂离时给该人物一个可理解的去处。回归时选择一处变化让时间可见，例如以前借船的孩子已学会替人撑篙。上一卷的每位租客都回来亮相，会挤走必须收束的人物。
- 伏笔分三种读法。对“谁拿走胶片”的主动悬问，应有足以检验的回答。两人争着坐外侧可随亲疏反复。岸边一朵晚开的花也可只存在一次。别将每个细节列为欠读者的答案。
- 需要管理一条长线时，在现有工作材料里留下“出现位置／当时读者可推知什么／谁实际知情／后来哪种行为使含义改变”。未来发展可改；重规划时先保住读者已经读到的东西。
- 人物弧线可以朝相反方向走。姐姐越来越愿意借船，弟弟越来越怕再欠人情；两人都曾帮忙，并不意味最后还要意见一致。群像切换的理由是另一个人的行动改变了局势。按平均页数分配镜头容易把群像写成点名。
- 能力成长后的冲突可以换性质。学会修机器后，矛盾转向是否给对岸竞争者修机器。补设一台更难修的机器虽省事，连续使用会抹去技术增长的实际效果。

## 停滞诊断

|读者读到的问题|回到正文找什么|有限修法与保留项|
|---|---|---|
|三卷只是不同地点的相同委托|把三个结尾写成动词；地名一换也能互用吗？|选一次委托的受益者，让他下一卷取得谈判权。委托集本来承诺单元乐趣时，保留其重复仪式。|
|角色总为原定高潮让路|人物最后一次坚持或拒绝在前文何处？当前压力足以改变它吗？|允许拒绝成立，让另一人承担原剧情功能，或换掉原高潮。|
|中部都很忙，却不知道要等什么|读卷首和中部两章，找人物仍愿等待或畏惧的事|把较远的结果移近一步，例如先听到修船厂拒绝接活。无需凭空再起一场灾难。|
|后半部不断引入更高层势力|列出未兑现的少数核心问题；新人物若不登场，旧人物可否处理？|把线索转回已出场者。若新事物正是最终发现的主题，让它提前以痕迹出现。|
|形式收束了，却没有结局|最后一章中开篇人物付出了什么，谁还在过改变后的日子？|在大事件后留出恰当的日常时刻。开放式结尾可把决定写清，将其远期结果留给读者。|

长篇方法的实际出处和适用范围见[研究记录](../../research/literary_agents/LITERARY_METHODS.md)。短篇或中篇的实验只可验证其中在该篇幅真实出现的环节。
