# 小说写作与编辑方法索引

先说明眼下要作的选择，只取对应条目和一个反例。编剧、导演与编辑可在获准素材内引用一小段方法，作品事实和人物知识仍来自该任务绑定的世界与披露切面。RuntimeCatalog 只读取选定角色和单项技能正文，正文里的链接没有递归加载功能。

| 遇到的问题 | 查阅 | 用后应能做什么 |
|---|---|---|
| 人物说起话来一样，叙述离角色太远 | [人物、对白、时间与视角](STORY_CRAFT.md) | 决定由谁先看见具体事物，谁仍然误会 |
| 中段重复，结局凭空引入解法 | [长篇组织](LONG_FORM_NOVEL.md) | 追出开篇承诺和后继场景真实继承的一项后果 |
| 正在选题，或混合题材的期待冲突 | [中文网文题材](CHINESE_WEBNOVEL_GENRES.md) | 明确主要读者等待的兑现，选可兼容的另一种机制 |
| 感觉文字整齐却没有人味 | [模式和反例](AI_WRITING_PATTERNS.md)、[局部试改](NATURAL_PROSE_EDITING.md) | 找到两处阅读损失，保留一个有功能的重复或概述 |
| 要给作者一项能执行的审稿意见 | [文风审核](AI_STYLE_REVIEW_PROTOCOL.md)、[文学编辑](LITERARY_EDITING.md) | 给出原句、反解释、影响范围与编辑决定，限制返工 |

研究依据见[作家与叙事学](../../research/literary_agents/LITERARY_METHODS.md)、[社区原帖与证据等级](../../research/literary_agents/COMMUNITY_AI_STYLE_RESEARCH.md)和[写作系统比较](../../research/literary_agents/OPEN_SOURCE_SURVEY.md)。创作结束的独立评分另用[固定量表](../literary_evaluation/QUALITY_RUBRIC.md)。
