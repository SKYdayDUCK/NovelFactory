# 组织图与等级通信协议

## 图的含义

用户的默认入口是 workshop_manager。其直接管理编剧、总导演、审核主管以及按需设立的维护主管。总导演主管卷纲导演，卷纲导演主管演员。编剧与总导演之间还有一组显式的同级协作边。管理树无环，每个在职员工有一个直接主管；通讯图允许双向边。两者分别校验，才能同时满足“管理者直接管理编剧和总导演”和“编剧经总导演传递创作意图”。

| 来源 → 去向 | 允许消息 | 语义 |
|---|---|---|
| 编剧 → 总导演 / 总导演 → 编剧 | PROPOSE_SCRIPT / REQUEST_REVISION、REPORT | 交换情节方案与执行反馈；协作边仅允许列出的种类 |
| 总导演 → 卷纲导演 / 反向 | ASSIGN、PAUSE、REQUEST_REVISION / REPORT、ASK、REQUEST_DECISION | 一次委派绑定一项工作、一卷或一个有限窗口 |
| 卷纲导演 → 演员 / 反向 | ASSIGN、PLAN_NOTICE / REPORT、ASK、REQUEST_RESOURCE | 演员返回行动意图与自身视角的依据 |
| 任一员工 → 直接主管 | EXCEPTION、REQUEST_REVIEW | 敏感证据采用引用；主管按授权读取 |
| 审核主管 ↔ 专业审核员 | ASSIGN_REVIEW、REPORT | 附审核模式、冻结产物、独立性要求与截止时间 |
| 员工 → 应急入口 | INCIDENT | 仅白名单故障类别；限频、有限有效期，记录签发和接收方 |

## 消息契约

每封信带 org_id、graph_revision、message_id、operation_id、causation_id、sender/recipient、sender_employment_revision、kind、scope_ref、body_ref、expires_at、可选 route_grant_id。sender 从经认证的连接绑定。body_ref 指向按敏感级别存放的工作材料，收件人每次读取重新鉴权。同一消息的传递确认只证明收到，业务完成由独立回执说明。

发送时检查在职状态、边方向、种类、组织和作用域、有效期，锁定相关版本并由 outbox 投递。接收或执行命令时再次检查当前任期、路由与授权。网络重复按同一 operation_id 返回既有回执；同键内容不一致报 IDEMPOTENCY_MISMATCH。并发撤权优先按事务提交顺序判定；撤权后已入队未执行的委派进入 ROUTE_REVOKED，保留历史送达证据。每封信一个收件人，群发由带固定目标集的服务事件派生单独投递。

编剧要求演员改变对白时，服务应拒绝直接命令，可由总导演判断后给卷纲导演新的委派。中继生成新的 message_id，保留 causation_id，重新评价允许传出的材料。临时授权逐项限定两端、类型、作用域、次数、截止时间和签发者；原子消耗一次使用额度，禁止转授。应急通道向运维报告故障编号和影响范围，不附小说人物秘密。

## 目录与循环

变更图时校验主管无环、员工端点有效、必需任务有合法返程，并检查关键审核有独立接收身份。普通消息带根目标、跳数和处理预算，同操作回复复用幂等键，同问题重复转发或预算耗尽进入人工决议。名册通知走系统专用广播边，可更新目录版本，不能执行任务指令。目录仅显示可见员工身份、岗位、团队、直属关系与可请求的路由；人物 BELIEF 编译器只接受 NF 授权的小说证据。
