# 专业审核与模型成本控制

审核任务从同一受控队列按模式创建；原执行者、共同作者、拥有产物批准权的直接代理和退休任期均不得自审自批。组织管理层分配工作，NF 决定作品操作是否获批。系统稳定性和统计审查可以由程序完成，只有确有解释或判断需要时才启动审核模型。

| 模式 | 输入 / 可见范围 | 触发与产物 |
|---|---|---|
| 编剧审核 | 冻结卷纲、选定主题和允许的因果链 | 核心动机或冲突变化；返回候选问题、节点和改写选择 |
| 导演审核 | 场景窗口、出入场约束和上下场交接 | 关键场景换序、演绎偏离或节奏抽样；返回执行问题 |
| 角色审核 | 某一人物授权 BELIEF 快照与台词/行动 | 人物使用新知识、动机突变；标注具体引文和时间切面 |
| 文笔审核 | 文本版本、选段、叙述声音与风格合同 | 标记视角跳变、语言表现和过度复述；给出修改意见 |
| 世界一致性 | WorldRef、时态关系、资源账本、规则证据 | 程序先验时间/资源/版本；不确定含义交给受限语义审核 |
| 系统稳定性 | 有范围的操作日志和故障收据 | 租约冲突、重复业务效果、未恢复的工作；升级运维 |
| 统计审核 | 指标版本、冻结水位、增量与重建差异 | UNKNOWN 调用、缺失账单、统计漂移；产出差异与证据 |

审读请求包含 review_mode、artifact_ref、允许的证据类型、风险原因、作者身份、预算、deadline 和额外一轮的触发条件。量化硬规则失败直接阻止相应操作并记录规则版本。文学问题保存文本位置、解释、建议与最终决定，不能把模型自评分当作人工质量金标准。章节、场景与人员抽样采用冻结的规则版本、分层样本和抽样种子；高影响规则、正式 Retcon、披露越权必须独立检查。

## 预算与防循环

组织级预算包括可支配金额、预留金额和可用 Tokens。每次委托先用 org_id、budget_epoch 和 operation_id 原子预留；包含推理、查工具后续轮次和复审的总上限。NF 生成 attempt_id 后与该预留绑定，费用结算使用 NF 的调用账本。估算价、供应商报告金额与对账账单分列；缺少账单标为待核。监控开销需区分作者管理、创作、审核和重复工作。

示例仅用于设定试验参数：某场授权 12,000 Tokens，创作 8,000、审读 3,000、异常处理 1,000；已保留的输出额度计入上限。追加预算必须有新授权收据。生成成功但结果失效时保存已发生的消耗；调用为 UNKNOWN 时继续占用预留，仅能对账，禁止换键重发。未实际调用模型的规则验证记录零额外模型调用。

每个整改工单有最大轮数、最大未来节点数和到期时间。两轮意见及产物哈希相同，或剩余额度不够下一次最小请求，停止自动派工。原文仍保留，作者可在有限选项间决议。检查管理者睡眠与通知链时记录 READY 到首个模型请求的延迟，以及空闲窗口的调用次数。工坊的预算视图进入不可变日志，按相同事件集合重放应得到与增量路径一致的结果。
