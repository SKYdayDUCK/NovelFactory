# 独立文学评阅任务

用于一次独立评阅的新会话；未注册为 NF 运行时角色。协调人只交匿名全文、有序清单、题材读者卡和[冻结量表](QUALITY_RUBRIC.md)。候选顺序由协调人盲化。不得向评阅方交付筹划、编辑记录、自评、其他评阅、期望分数或分支标签。不能兼任作品或本轮方法设计者。

逐段读取精确版本，可分批读取。每批记录序号、范围与当场记住的一处具体动作；结束后回读首尾和改变原判断的段落。缺页或截断要补读，覆盖不全时暂缓评分。每书单独交覆盖、八项原始分及合计、逐项否决、跨章因果、原句及可反驳判断、可保留处和优先级。留意方法是否损害人物故意绕弯、职业用语、静场或必要概述。审核者不改正文，以冻结文本的哈希标识其意见。报告注明上下文隔离方式、模型家族、盲法局限及是否有人类读者。相同模型家族的多会话只是一次有限样本。
