# 接口参考

[English](../en/07-api-reference.md) · [模型运行时](05-Agent-Runtime.md) · [配置与部署](08-配置与部署.md)

源码注册了 34 个 NovelFactory 工具、34 个 Workshop 工具、2 个安装委托工具和 28 条 HTTP 路由。宿主按当前绑定身份提供其中的子集。实际授权由服务端逐次核验。每一项都可以查到输入定义、测试中的请求与结果、对应处理代码。

## 如何使用本页

输入字段末尾的 `?` 表示可选。`WorldRef` 等命名类型对应 Schema 定义。嵌套字段、长度、枚举、默认值和条件分支见该项的定义链接。未传入可选字段时，服务按处理代码取值。返回字段列出所附示例中的 JSON 类型，`null` 表示该次调用返回空值。有多种结果形态的工具另列触发条件。示例标有测试来源，照做时使用该测试创建的对象，或换成本项目中有权访问的标识。

HTTP 示例中，20 项来自直接路由调用，另 8 项将路由规定的请求与应用服务实际返回的结果配对。MCP 示例包括 62 项服务测试记录、4 项直接调用 Workshop 处理函数的结果和 4 项 NovelFactory 应用服务结果。调用 MCP 时，将示例的请求放入 `params.arguments`。HTTP POST 使用 JSON 请求体，GET 按路径替换对应参数。

```json
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"nf_resume_project","arguments":{}}}
```

先由宿主初始化已绑定的 MCP 会话。成功时读取 `structuredContent`，工具错误见 `isError` 和 `structuredContent.error.code`。通用错误包括 `VIEW_DENIED`、`INVALID_ARGUMENT` 和 `SERVICE_UNAVAILABLE`。Workshop 逐次检查任职版本，参数 JSON 上限为 32,768 个 UTF-8 字节。任职失效可返回 `STALE_EMPLOYMENT`。安装端口还要核对安装启用状态、有效期、策略版本及当前授权。

HTTP 受限接口使用 Bearer 凭据。请求体默认上限为 262,144 字节，读取时限为 5 秒。错误响应附请求 ID。鉴权失败和越权分别对应 401 和 403，资源缺失对应 404，请求过大和媒体类型错误对应 413 和 415，Schema 错误对应 422，多数状态冲突对应 409。读取超时可返回 408。准入与服务可用性错误可返回 429 或 503，并附 `Retry-After`。重试前按具体接口核对回执和幂等键。[HTTP 适配器](../../src/novel_factory/interfaces/http.py)

## 管理与开发入口

| 入口 | 用途与身份 |
| --- | --- |
| `aw-migrate`、`aw-provision`、`aw-admin` | 数据库所有者或安装管理员执行迁移、创建安装绑定，管理凭据与授权。 |
| `aw-mcp`、`aw-manager-run`、`aw-reconcile` | 启动绑定的工具服务，分派已获准的工作，或按回执核对未完成的委托。 |
| `scripts/p58_bootstrap_book.py`、`scripts/provision_resume.py` | 初始化作品并绑定作者的恢复入口。每部作品使用独立的私有目录。 |
| `scripts/run_supervisor.py`、`scripts/runtime_policy.py`、`scripts/runtime_limits.py` | 运行已绑定的 Supervisor，或管理调度策略及额度。权限和配置见运行时与部署章节。 |
| `scripts/p55_statistics.py`、`scripts/p55_chapter_costs.py`、`scripts/p6_reconcile_invoice.py` | 读取运行统计、追溯章节费用，或核对另行取得的账单证据。 |
| `scripts/backup.py`、`scripts/pitr_drill.py` | 创建备份或在隔离环境演练恢复。选择目标库之前先核对恢复手册。 |

应用层 Python 类实现上述服务。基准模块用于隔离实验。供应商配置和路由规则由操作人员提供。模型可调用的工具受任务绑定限制，员工聘任、预算和权限由服务端决定。[Workshop 命令入口](../../workshop/pyproject.toml) · [模型运行时](05-Agent-Runtime.md) · [运维与恢复](09-运维与恢复.md)
