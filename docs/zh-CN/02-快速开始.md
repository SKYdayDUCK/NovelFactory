# 跑通第一部短卷

[English](../en/02-quick-start.md) · [项目首页](../../README.md)

这次运行会在临时 PostgreSQL 集群里创建一部六场短卷。你可以阅读正文，逐场查看上下文和审核结果，再对照写作前后的世界事件。示例使用确定性模型夹具，无需模型账号。

## 准备环境

在 Linux 或 WSL2 的普通用户终端准备 Git、uv 和 PostgreSQL 17 的服务端及客户端工具。以下命令使用仓库锁定的 Python 3.12.14；可用的磁盘空间需要容纳 Python 环境、一份临时数据库和本次输出。

```bash
git clone https://github.com/SKYdayDUCK/NovelFactory.git
cd NovelFactory
uv python install 3.12.14
uv sync --locked --group dev
export PG_BIN="${PG_BIN:-/usr/lib/postgresql/17/bin}"
"$PG_BIN/postgres" --version
```

如果 PostgreSQL 安装在其他目录，将 `PG_BIN` 设为同时含有 `postgres`、`initdb`、`pg_isready` 和 `psql` 的目录。使用 Docker 的配置见[配置与部署](08-配置与部署.md)。

## 生成并检查样卷

从仓库根目录执行。脚本会选择空闲的本机端口、初始化数据库、运行迁移，然后启动写作流程。退出时会关闭临时集群。下面将正文、对象和运行日志保存在同一个新目录，便于复核。

```bash
export NF_DEMO="$(mktemp -d)"
.venv/bin/python scripts/with_postgres.py --migrate --log-dir "$NF_DEMO/postgres" -- \
  .venv/bin/python scripts/run_short_volume.py --execution-kind TEST_FIXTURE \
    --object-root "$NF_DEMO/objects" --output "$NF_DEMO/book"
```

| 文件 | 可以核对什么 |
| --- | --- |
| `book/short_volume.md` | 《潮闸余灯》的六场正文 |
| `book/run_manifest.json` | 执行类型、场次数、模型调用量、工程和作者评估状态 |
| `book/process_trace.jsonl` | 各阶段的执行顺序和回执 |
| `book/initial_plan.json`、`book/final_plan.json` | 写作前后的规划 |
| `book/world_receipts.json`、`book/contexts.json` | 世界变更回执与任务读取的材料 |

```bash
.venv/bin/python - "$NF_DEMO/book/run_manifest.json" <<'PY'
import json
import sys
from pathlib import Path

run = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
for field in ("engineering_status", "scene_count", "model_fixture_call_count",
              "real_model_call_count", "literary_quality_status"):
    print(field, run[field])
PY
```

验证运行的结果为 `PASS`、6 场、15 次夹具调用、0 次真实模型调用。写作前后均有 7 个已接受世界事件。文学评分状态为 `NOT_EVALUATED`。可以从 `short_volume.md` 开始阅读，再用 `author_feedback.md` 记录反馈。
