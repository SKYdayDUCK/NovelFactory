# Migrations 局部规范

本文件继承 [根规范](../AGENTS.md)，迁移方案与真实环境执行分别判断授权。

- 可自主创建候选 Alembic 迁移并在隔离数据库验证；不因文件位于本目录而要求额外确认。
- 记录起止版本、影响表、锁范围、预计数据规模、可恢复进度和验收查询。
- 默认采用扩展、分批回填、校验、切换、最后收缩；大回填不放进长阻塞事务。
- 不就地改写正式事件、审批证据或历史正文；需要修正语义时用新版本/解释器/修复分支。
- 历史表和核心约束的破坏性修改提供明确的数据保留与恢复方案。
- 单个 downgrade 不等于业务可恢复；说明代码回退、数据恢复及对象清单如何配合。
- 验证升级后旧记录可读、约束仍成立、并发与重试没有改变可接受结果。
- 真实生产迁移、恢复覆盖或不可逆清除超出现有授权时，先提交具体差异和验证结果请求授权。
- 不记录凭据；开发连接配置与生产连接清晰区分，执行前核对目标环境。
- 迁移失败保留诊断信息和检查点，不自动通过删库或清空历史“修复”。

- 改变reducer/projector/谓词/历法解释时维护interpretation_ref和语义守卫epoch；普通索引重建不伪装成世界修订，旧历史不能静默换解释。

参考：[04 版本](../docs/04_事件溯源与版本体系.md)、[11 验收](../docs/11_研发路线与测试计划.md)、[12 ADR](../docs/12_架构决策与风险.md)。
