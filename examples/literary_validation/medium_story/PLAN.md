# 《借冬衣》开稿登记

现实题材的后台行业群像，含一出原创滑稽布袋戏。读者为喜欢剧团生活和手艺故事的普通成年读者。九章，正文 30,000–38,000 汉字。单卷完结。叙述贴着学徒林穗所见所闻，可短暂跟随他人但须有清楚的场景边界。山间镇石沽、青杠偶班和戏文均为虚构。中心问题是林穗能否排成一出可以再次上路的戏，谁愿意带着它走；首演效果和个人去留允许分离。

| 章 | 场面与待解决的问题 |
|---|---|
| 一　晒偶 | 老库冬前腾空。遇到一个只有窄门的流动演出机会，林穗争取试演，老班的人各有去处。 |
| 二　袖筒 | 戏名《借冬衣》。旧戏只演过半场。年轻人盘点实物与手上真能演的段落，尝试搭档，碰上活与人不匹配。 |
| 三　试口 | 一次小范围试台，最用力的一段落空；意外有效的笨拙动作留下。场地方只肯出两个流动名额。 |
| 四　窄门 | 为过窄门拆旧台或另做小台，团内谈钱、工时、谁能离家。有人拒绝白干。 |
| 五　错褂 | 试着演下半场，借来的衣裳穿错人；一场场外的人情干扰排演，班里争执酬劳归属。 |
| 六　背场 | 旧半场的现场缘故从互不相同的记忆浮现，可承认不知道的部分。决定舍去对旧演法的完整复原，携带一种真有用的东西去首站。 |
| 七　头站 | 在镇外第一站演出，地方和观众有自己的秩序。原先的救场办法失灵，台上失手有后果。 |
| 八　换手 | 谁替谁托住偶，谁决定何时收场。现实中的岗位也要换手，拒绝无偿替人。 |
| 九　收戏 | 最后一次演出的结尾兑现喜剧的承诺。班子收拾去路、下季工与离场的人有具体着落；留一项不重要的老戏细节无解。 |

人物固定关系：林穗是学徒，手快，想得下一季有工钱的岗位；孔师傅是老台口，掌旧戏节拍；游湘是兼做服装的演手，有照料负担；鲁旺是接活和跑车的班主，车与人工要付钱。无家族秘密、万能资助或遗嘱。核心物件为一件红褂和一座宽旧台。戏内是卖豆腐的人借衣进亲家门引出的喜事误会，角色姓名和小动作由写作交接确定。独立人物提案与材料实测可改变本表中的将来路线。
