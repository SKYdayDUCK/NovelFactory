# Contracts 局部规范

本文件继承 [根规范](../AGENTS.md)，本目录维护跨模块与外部边界的数据契约。

- 标明 Schema 版本、权威责任方、输入输出方向、必填字段和兼容性策略。
- 示例必须通过所引用的 Schema；示例枚举、错误码与正文文档保持一致。
- 显式区分 WorldRef、故事时间、任务代际、事件/效果标识和正文版本。
- 未知、未推进、未来计划及派生索引滞后使用明确语义，不能统一为 null。
- 对象中多余字段的处理显式定义；不能依靠宽松解析隐藏调用方拼写或版本错误。
- 格式校验不能替代授权、审批、跨字段规则、时态前置条件和并发检查。
- 旧事件原文保持可读；不通过就地修改 Schema 默认值悄悄改变历史含义。
- 破坏性变化附迁移/适配方案及调用方影响，不把一次类型重命名当成完整迁移。
- 候选契约可自主编写验证；扩大真实角色权限或清除历史数据另按已有授权执行。
- 新增契约应有最小合法例与能表达真实边界的非法例，不枚举所有设想字段。

- core 2.0保持原样，新增2.1类型与旧接口并存；检查ReadContract/KnowledgeCut、解释版本、证书字段及同cut批量约束，不能把Schema通过等同服务端签发。

参考：[03 数据](../docs/03_数据模型与知识图谱.md)、[04 版本](../docs/04_事件溯源与版本体系.md)、[08 接口](../docs/08_MCP与工具接口.md)。
