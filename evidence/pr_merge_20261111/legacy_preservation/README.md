# 本地历史独有材料保全

接管时逐文件核验的 96 个本地独有或已被远程后续版本取代的材料，原字节归档在 `historical_unsynced.tar.gz`。它们只供历史审计及恢复，不进入正式源码、测试发现或验收统计。旧 Retcon 用例及其失败记录仍保留，不声称通过；旧规划接口不覆盖现行派生工作者实现。

`index.json` 保留原路径、Git blob、逐文件 SHA-256、分类、远程对应 SHA 以及归档 SHA-256。归档生成后已逐成员解压复核全部 96 个哈希；临时路径、合成作品/任务及失败日志原样保留。已与初始 PR3 完全一致的文件继续由 Git 历史保存，不重复打包。没有删除或重写任何旧目录。

恢复时先验证归档 SHA-256，再解压到新的审计目录；依照 index 的逐文件 SHA-256 校验。勿直接解压覆盖当前工作树。所有归档成员均为相对路径的常规文件。
