# P3-03：文学记忆与检索评测基础交接

日期：2026-11-10。状态：**EVALUATION_FOUNDATION_CANDIDATE**。本批没有开启 P3-02、P3-04 或 P4，也没有把工程检索结果记为文学质量验收通过。

## 已实现范围

新增一个无 I/O 的候选排序与原文装配算法，以及可复现的中文数据、配对评测脚本、金标准、实际服务探针和测试。既有 Kernel、公开契约、数据库迁移、权限和世界解释均未为此扩权或更换。

纯算法只消费已授权候选，不拥有世界真相。它验证来源 SHA-256、以中文二元字片/实体匹配排序，选择性地扩展已授权的一跳来源链接，按完整 UTF-8 段落装配，保留所有省略 ID。未接入生产调用链，不能被描述为整个 P3-03 已完成。

## 确定性配对结果

语料包含 48 章、384 个来源段、78,952 个 Unicode code point；其中 40 个受控原创来源单元承载规则、情绪、关系、伏笔、认知、声线及版本反例，其余是确定性展开的背景间隔。35 题中 28 题检查必需证据，7 题检查作用域隔离。4 个方法 × 3 档统一字节预算，共 420 个真实本地运行记录。模型调用数为 0，token 和费用未测量。

| 表示 | 1,500 字节：必需证据宏召回 / 完整题数 | 3,000 字节：必需证据宏召回 / 完整题数 | 6,000 字节：必需证据宏召回 / 完整题数 |
|---|---|---|---|
| 普通摘要：固定首尾摘录 | 0.6905 / 17 of 28 | 0.6905 / 17 of 28 | 0.6905 / 17 of 28 |
| 结构化人物原文索引 | 0.7083 / 17 of 28 | 0.7560 / 20 of 28 | 0.7560 / 20 of 28 |
| 时态来源图，关闭链接 | 0.9524 / 25 of 28 | 1.0000 / 28 of 28 | 1.0000 / 28 of 28 |
| 时态来源图，启用链接 | 0.9702 / 26 of 28 | 1.0000 / 28 of 28 | 1.0000 / 28 of 28 |

每个方法每档均通过 7 个离线作用域反例，禁止来源命中为 0。这个结果由共同的固定切面筛选支持，不是“模型不会幻觉”的证据。所有题目明细、遗漏、排序分数、源码/数据 hash 在 [最终摘要](../evidence/p3/memory/final/summary.json) 和 [逐题记录](../evidence/p3/memory/final/cases.jsonl) 中。

关键解释：三类表示的可用来源覆盖不同；固定首尾摘录会遗漏中间的反证，人物索引会遗漏不直接关联人物的规则和资源记录。因此不能把差值单独归因为图结构的收益，更不能推广到真实 LLM 摘要。窄消融显示，1,500 字节时来源链接只多完成 1 题；到 3,000 字节时有链接与无链接相同。当前语料对足量上下文仍然偏容易，不能据此要求引入新数据库或复杂重排器。

问题组同时保留了确定性冲突与主观编辑选择：r1 世界中钥匙已毁而正文仍使用完整钥匙，需要硬一致性处理；“笑后是否还需擦杯动作”保留原文和反证，等待编辑裁决。评分只计算证据是否获得，不自动判断后者应当保留还是删改。

## PostgreSQL 实际服务证据

独立运行使用 PostgreSQL 17.11，`fsync=on`、`synchronous_commit=on`，连接上限 60。探针通过 Kernel 正式接受青霜剑历史，再创建、领取和编译真实任务。每种策略创建三份独立任务，SQL 计数仅覆盖 `context_compile` 调用：

| 编译输入 | P3-01 前每次 SQL | P3-01 后每次 SQL | 前后必需 section UTF-8 字节 | 目标状态是否正确 |
|---|---:|---:|---:|---|
| 单对象、单谓词 | 51、51、51 | 47、47、47 | 1,158 | 前后各 3/3 正确 |
| 八对象、四谓词 | 68、68、68 | 47、47、47 | 2,237 | 前后各 3/3 正确 |

优化前运行使用继承 `0609f680` 的核心，优化后另开隔离数据库重复同一未修改探针，九项工程门禁仍全部通过。优化后集中输入 SQL 减少 4 次，宽输入减少 21 次，与 dependency INSERT 合并相符；上下文预算与目标状态判断未变。两个时间段分别建立自己的合成世界，不能要求包含随机 WorldRef/事件身份的完整上下文 hash 相同，亦不据此声称跨运行逐字证据一致。每份结果的 `implementation_sha256` 标明实际实现。

这是小数据服务正确性与 SQL 成本观测，不是生产容量承诺。优化前另有开发负载并行运行，延迟仅保留为原始描述值，不据此计算速度提升。P3-01 的严格语义与性能对照另见 [同一 WorldRef 配对实验](../evidence/p3/context/paired-run.json)：它在同一真实数据库上加载并校验旧实现，轮流编译独立真实任务，保留完整证据比较，避免跨世界身份带来的错误比较。

实际运行同时通过九项门禁：

1. 集中和宽输入均保留目标对象的真实持有人。
2. 同一编译请求重试返回同一持久回执。
3. 角色仍相信友人持剑，不从世界客观的被盗结果偷取知识。
4. 角色请求 WORLD 或另一角色视图被拒绝。
5. 热查询缓存与旧编译回执均在撤权后拒绝交付。
6. 历史状态可回查；固定旧修订的未推进区间仍为 `PENDING`。
7. 已毁工具 `NOT_APPLICABLE` 与未来未求值 `UNRESOLVED` 不混淆。
8. 必需上下文超预算返回 `CONTEXT_INCOMPLETE`，没有半成品绑定。
9. 查询、编译和撤权过程没有增加事件、改变世界头或状态 hash。

完整请求/响应、种子事件回执、实体映射与 SQL 数分别见 [优化前探针](../evidence/p3/memory/probe/service_probe.json)、[优化后探针](../evidence/p3/memory/probe-after-c/service_probe.json)；隔离数据库配置分别见 [优化前会话](../evidence/p3/memory/probe-pg/postgres_session.json)、[优化后会话](../evidence/p3/memory/probe-after-c-pg/postgres_session.json)。探针与离线文学图使用不同测试素材和端口，报告不把二者混成“生产图检索已完成”。

根 Agent 的交叉审核还发现，初版排序器虽然不沿隐藏链接扩展，但返回的 Passage 元数据仍保留了隐藏链接 ID。现已在构造返回对象前把 `related_source_ids` 限制在完整授权 ID 集合内，并验证 `dataclasses.asdict` 序列化也不泄漏隐藏 ID；不能只检查打包正文。

## 尚未完成的验收

真实模型的摘要、人物档案和文学文本未参与本次比较；没有真实供应商 token/费用、真实文学质量提升、独立作者全文反馈，也没有把开发 Agent 写的受控素材冒充模型生产结果。普通摘要、人物记忆、图检索的真实收益仍需同预算、同来源、冻结样本与独立标注的中文作品对照。长程情绪、声线和主观审稿的结论需盲化配对阅读；LLM 自评分不能替代作者裁决。

本批可交付范围是 **P3-03 可运行评测基础与候选算法**，不是完整文学消融验收。P2 真实模型或作者门槛若仍未完成，本批保持候选状态，停止于用户限定范围。
