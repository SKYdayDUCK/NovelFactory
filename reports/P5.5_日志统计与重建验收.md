# P5.5 日志与统计验收

本地使用 PostgreSQL 17.11、Redis Streams、Python 3.12；两种模型验证分别使用明确标为 TEST_FIXTURE 的内存适配器、真实 Codex app-server 加回环 HTTPS 供应商。供应商商业支出未实测。

| 长事务和历史来源 | DONE | 快照准确排除稍晚提交的另一事务，后续快照发现 1 个未处理事件。移除 6 次正式提交的已归档 Outbox 后，import-legacy 从 PG revisions、commits、receipts 补回 6 条；第二次补回 0 条。累计指标只计算每次回执新增的事件。超过 16 个不同管理员切面时回收最久未使用令牌，两个作品和角色授权分别受控。 |

| 章节归集与版本价卡 | DONE（显式来源） | PG17 管理员应用及真实 CLI 在同一来源水位、相同两个 ArtifactRef 下返回完全一样的逐章结果。同章重复场景只计一次；隔离测试中两个调用分别产生 0.01 USD 和 0.02 CNY 夹具金额。独立示例价卡估算 0.000145 CNY 和 0.000042 EUR。跨作品、跨分支、跨章重复、错误卷/对象身份、重写同一版本、非法费率、未知用量和未完成调用有明确拒绝或缺测语义。证据见 evidence/p55/chapter-costs.xml，两项逐章专项加六项原统计回归，共 8 passed。 |
| 实际生产 | BLOCKED_ENVIRONMENT | 没有商业供应商账单、真人审读和作者 Windows 设备。部署历史越长，首次构建切面及比较所有贡献的工作量越高；16 份切面上限不等同于任意规模查询已通过。 |

S6 统计专项 5 项通过，见 evidence/p55/statistics.xml。S8 扩展后同步运行 6 项统计、4 项 MCP、13 项真实 Host 角色工具选择场景，23 项全通过（17.01 秒，evidence/p55/accounting-final.xml）。选择工具与最终生成各 29 个合成 Token、各 0.05 USD 时，总计 58 个夹具 Token 与 0.10 USD 夹具金额。非 OpenRouter 受信 Host 报告金额、OpenRouter 生成级费用、供应商发票分列；本轮真实供应商发票缺席。场景链 1 项和 stdio MCP 4 项单列；叙事回归以及上述部分测试合并运行过 17 项，见 evidence/p55/observability.xml。这些数字存在覆盖重叠。开发中首轮统计专项出现测试 SQL 将 JSON 数字误解为命名绑定，故障注入改用 jsonb_build_object 后重跑通过。
