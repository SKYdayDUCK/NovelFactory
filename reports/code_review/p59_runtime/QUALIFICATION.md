# Regression and release evidence

The frozen main export and each candidate checkout used its own locked Python environment. The full Linux suite used two native PostgreSQL 17.11 clusters, Redis 8.0.2, subprocess stdio and a disposable object root. The Workshop service had its own database. Counts below use pytest's terminal convention, which lists subtests separately. JUnit includes those subtests in its total.
