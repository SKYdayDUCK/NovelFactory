# Native deployment review

Baseline `434840593179e6c1faa6b7aeca3d7d747644506d`. Windows and Linux run ordinary native Python 3.12 processes. PostgreSQL and optional Redis can run separately. The Windows acceptance uses PostgreSQL 17 as a native service on the hosted runner.

| ID / severity | Source and trigger | Impact and cause | Remediation and evidence |
|---|---|---|---|
| NAT-01 / high | Import `novel_factory.infrastructure.objects` on Windows. Publish equal content concurrently or collect an orphan during a reference commit. | The import required `fcntl`. Directory fsync and `fchmod` were unconditional. The authoritative application could not start. | POSIX retains flock, file and directory sync. Local NTFS takes a shared/exclusive Win32 byte-range lock and publishes a flushed file with a no-replace, write-through move on the same volume. The evaluation ledger reuses the publication and lock primitives. `tests/reliability/test_objects.py` covers a killed writer, equal puts and GC exclusion. Native tests assert actual write-through flags. |
| NAT-02 / high | Read MCP bindings, review attestation keys, Workshop bindings and manager routes on Windows. Start the sample/book bootstrap. | UID, POSIX flags and ownership checks were missing on Windows. The supervisor read an administrator binding using an ordinary text read. | Verify the target's owner and ACL on the same open filesystem handle. Refuse broad/unrecognised ACEs and reparse points. Create secret files privately before writing bytes. Both service wheels package the same pure helper under separate module names. Native tests exercise positive, broad-ACL, bounds and invalid-data cases. |
| NAT-03 / high | Close a Host after its root exits while a helper remains alive. | PID-scoped Windows cleanup required a living root. The old host launcher could leave descendants with access to their private workspace. | The launcher joins its own kill-on-close job before starting the Host. Only the supervising process retains the job handle. An exact live process handle verifies the child is signaled after shutdown. The Linux regression independently covers multiple process groups. The Win32 launcher explicitly supplies all three stdio handles. |
| NAT-04 / high | Run the original frozen migrations after checking out on a standard Windows runner. | Git converted LF to CRLF. Alembic correctly rejected the changed bytes in migration 0002, preventing deployment. | Checkout attributes preserve canonical bytes across platforms, with exceptions for the historical CRLF CSV and mixed-EOL literary source. The digest checks and migrations are unchanged. A local `core.autocrlf=true` checkout of source `892f350` matched every one of 4,342 regular-file blobs. |
| NAT-05 / medium | Provision a branch resume credential and use it through the local operator command. | Windows ignores the owner-only protection intended by POSIX mode 0600. The administrator control token and the branch resume grant have distinct roles. | The new `grant-resume` operator alias calls the original provisioning service, pins the optional existing private administrator binding to the database, object root and project, and creates an exclusive owner-private output. The PG-backed CLI test checks rejection of administrator-as-resume, grant issuance, refusal to overwrite, status and idempotent bootstrap. |

## Scope of the receipts

The local Linux native selection covered 32 tests plus three Windows-specific skips. The independently installed Workshop passed its native binding check and original POSIX link-refusal test. The fresh PG17 operator, task-recovery, graceful-drain and route-quota run completed 27 tests. The three packaged wheels imported in isolated interpreters outside the checkout. The Windows and Linux jobs publish a JUnit receipt from the native runtime workflow on each PR and main push. The selected Windows cases include a stateless simulated provider. Actual billed requests and hardware power-cut durability have independent acceptance boundaries. Realm-wide role-tool isolation using Bubblewrap and the original dual-service container template retain their Linux dependencies. macOS native qualification was not executed.
