# 操作者独立复验原件

复验对象为 P5.8-A 候选 `60641790dabe34c3b9f68a7820c794f6287372d2`。所有生产推理凭据和实时派发开关均未注入。测试期间运行 Linux Codex 原生进程与本机模型协议夹具。Compose 解析使用随附的 TCP 健康检查修订。

| 原件 | 独立观测 |
| --- | --- |
| `evidence/operator.xml` | 从全新且不同的 NF / Workshop PostgreSQL 17.11 集群开始，执行管理者建权、两本书建库与预算绑定、两种角色预览及流水线登记。1 项通过。 |
| `evidence/providers-and-policy.xml` | 原生 CLI 本地协议、供应商适配器、超时、认证校验和路由政策，15 项通过，0 跳过。 |
| `evidence/preflight.json` | 两个 API 模板缺模型和凭据时退出 2。真实请求 0，双供应商线上并发为 NOT_EXECUTED，已结算费用为 null，文学质量为 NOT_EVALUATED。 |
| `evidence/independent-operator.json` | 记录 UTC 时间、候选 SHA、系统标识、环境版本、未填订阅配置的拒绝代码以及 Compose v2 校验结果。 |
| `evidence/budget-rehearsal.json` | 建书配置不变时可恢复。零预算预演后修改模板并复用原目录会收到 INVALID_ARGUMENT，更换作品目录可建立独立的新作品。 |

Windows 宿主、Docker Desktop 启动及线上模型账户仍需在授权的实验机检验。此复验没有供应商账单、真实正文或独立读者评分。GitHub 合并 SHA 与合并后的 CI 结果需由交付者另行登记。
