## 三臂、分母和成本

冻结输入、世界/分支/角色视图、初始状态、模型类型/版本或相同确定性夹具、时间与 Token 限额、运行器条件。A 为原静态系统，B 为开启 Harness、动态和候选优化关闭，C 为开启受限动态配置和离线优化候选。三臂分别报告真实派发、夹具回调、人工读者和批准次数。输入、评估版本与预算发生漂移时保留该次记录并标明不可比较原因。

| 指标 | 口径 |
| --- | --- |
| 场景及阶段 | 按唯一场景、task/generation、Attempt 去重。按规划、模拟、起草、审核、返工分别计调用、输入/输出 Token、耗时、币种和已知费用。UNKNOWN 单独给出数量及保留额度。 |
| 上下文与假设 | 记录字节、编译时延分布、实际加载来源数、生成/废弃/采用的候选数、模拟次数、停止原因及关联成本。未执行的场景不进入采用率分母。 |
| 审核与修订 | 给出覆盖位置/应核对位置、实际可复核问题/受核位置、修复/确认问题、无效返工/全部返工、复核通过/已复核。保留被反解释驳回、无改动和版本失效的条数。 |
| 版本与生产 | 报告每种角色/Skill/Profile 使用的版本、动态实例成功/撤销/失败数、候选通过/实际评估数及回滚次数。按工件和收据去重重放。 |
| 文学评价 | 对人物声音、行动/冲突、叙事因果、语言和接缝等分别保留证据、读者分歧和采编决定。独立配对评分存在时按维度报告同意的条数和分母。无评分时为缺失，文学结论保持 NOT_EVALUATED。 |
| 关闭模式开销 | 相同主机、同输入交错重放冻住的旧路径与新版本关闭路径，报告重复次数、样本量、p50/p95 与分布。首先核对调用/注册/授权读取这些可直接计数的增量。比较配对差值与同版本重复运行波动，超出波动的退化保留原数据并定位。历史 AT-30 继续应用 #13 原线。 |

## 复验次序

对每一阶段先运行相关专项和负例，再提交一个 PR。合并后使用该 merge SHA 的新 GitHub push 运行和没有改写的原始记录签收。GitHub 已跳过的宿主机隔离案例注明原因，并链接单独执行过的适用环境。历史容量使用原有标准，作者真实模型费用和文学观察只填实际获得的证据。阶段间复用[统一交付台账](../integration/DELIVERY_LEDGER.md)和[已知失败](../integration/KNOWN_FAILURES.md)。
