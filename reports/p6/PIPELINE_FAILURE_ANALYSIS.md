## 开发期间复现的异常

| 环节及工程输入 | 原始现象 | 定位、处置与验证 |
|---|---|---|
| 世界设计，模拟候选 | 受保护承诺/产物存储的字段形状不满足原生服务 | 通过可信服务生成类型正确的世界与计划；在创建新的正式作品前要求独立身份完成事实审核。对提出审查问题和账务未决分别进行 PG 反例测试。[灵感入口测试](evidence/idea-intake-postgres.xml) |
| 前驱交接，同窗三章 | 依赖场景在前驱接受前无法合法绑定 | 延迟建立依赖场的绑定；当前选定的前驱接受、场景、草稿和代际齐备后才放行。[窗口验收](WORKFLOW_ACCEPTANCE.md) |
| 账务，工程 HTTP 应答或写手中途退出 | 应答无可核对账单、或发送后中断时保持 UNKNOWN；跨窗不能继续 | 保留待核对的原 Attempt。通过 OS 终止已发送请求的写手，租约到期后只收到一次请求，未重复接受。[进程退出回执](evidence/writer-process-exit.xml) |
| 事实提取与历史接受 | 已完成的抽取任务先前可能在历史复核时被误拒。缺失覆盖或不确定事实不具备发布依据 | 原生服务复核历史任务身份、代际和依赖，允许核验已完成任务。对读稿漏字和不确定断言，保留失败或 BLOCKED 对账，接受数为零。[反例回执](evidence/rolling-blocked-facts.xml) |
| 终卷范围 | 最终候选可能仅提供自洽的小批次，或把多个场当作多章 | 核对全部冻结场的顺序、原始汉字/章节范围、逐写手真实 Attempt、全文哈希及两份评阅。同版登记、删段、错引、阈值及否决均有用例。[篇幅与原生出处](evidence/p6-manuscript-intake.xml) |
| 滚动义务与编辑签收 | 空事件/纯感官场景可以通过普通叙事接口；初始配置的 DAG 无法证明角色自主推进和环境事件均已发生 | 需取得相应 BELIEF 角色、语义裁决、正式事件与依赖失效/重规划回执。编辑及连续性服务还须对确切版本给出正式批准。[恢复验收](RECOVERY_ACCEPTANCE.md) · [本次签收范围](FINAL_P6_ACCEPTANCE.md) |

原生可用后，应从原输入重新执行预检和注册，按已授权金额和 Token 上限分作品留存日志。若遇 UNKNOWN，先核对同一 Attempt，再恢复同一任务。每书达到规定篇幅、有效世界和齐全审核证据后方可计算分数。
