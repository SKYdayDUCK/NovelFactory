# Production Profile 与三阶段任务图

`novel_factory.application.production_profiles.resolve_profile(preset, genre, overrides=None, complexity=None)` 在可信应用层解释配置。结果符合 `production_profile.schema.json` 的 `ProductionProfile`，含契约版本、篇幅、题材、复杂度输入、世界和规划深度、角色与环境演绎开关、未来卷数、记忆范围、写作与审核并发、窗口大小、章节与场景粒度、审核强度及返工上限。每次加载均重新验证规范；内容可由现有对象存储以 NF-CANON-1 指纹固定。

## 任务与证据

`compile_dag(profile)` 返回拓扑排序的节点。每个模型节点固定角色、任务模式和主 Skill。不可由作品配置替换角色、工具、Provider 凭据、权限或强制门槛。服务节点没有模型角色，其中的正式变更继续走 WorldRef、授权、代际和幂等校验。

| 阶段 | 可见任务 | 选配规则 |
| --- | --- | --- |
| 世界与规划 | 初始世界、人物身份、故事线、采用计划 | 世界细化、规则评阅、分卷、章纲、系列规划及前瞻依据配置启用。短篇的精简故事线仍需物化出合法的卷契约、已采用计划和场景输入。 |
| 演绎与创作 | 世界事件正式接受、场景输入、正文、版本化交接 | 人物和环境分别可设。行动需要语义裁决、已接受变化需要重规划时，启用对应条件依赖。长篇增加跨卷记忆与交接。 |
| 审核与发布 | 事实对账、认知和连续性、文学编辑、正式接受、两次独立全文盲评、内部发布 | 附加章审、卷审及定向修改由预设和实际审稿意见决定。出现未解决问题后须修订相应版本并重新核验。 |

节点记录两组信息。`decision` 为 `REQUIRED`、`ENABLED`、`OPTIONAL` 或 `SKIPPED_BY_PROFILE`。执行 `state` 为 `WAITING`、`BLOCKED`、`COMPLETED`、`FAILED` 或 `SKIPPED_BY_PROFILE`。`dependencies` 保存必要的前置节点，`conditional_dependencies` 保存由具体事件启用的前置节点。初次编译的活动节点都处于等待状态。

`project_dag(profile, execution_states, triggered)` 可从控制器观测到的同版状态重建节点视图。前置节点失败或阻塞会传递阻塞；若必要的裁决或返工已被触发，后续步骤需等它完成。已跳过的节点不能提交执行状态。此函数用于检查证据间的顺序，正式接受、评审和发布仍须回查真实服务回执。

## 授权和迁移

旧生产入口继续按原有的有界 board 契约运行。P6 新增的 `FirstWorldDesign` 可以单独绑定给新委托的 `world_designer / initial_world` 任务，旧任务的输出类型、Prompt 和角色授权保持各自原始绑定。五个预设均要求相同成稿版本的两份独立评阅和内部发布。正式创作轮数的上限与单个任务的返工上限分开计量。

## 测试范围

`tests/unit/test_p6_production_profiles.py` 覆盖五个预设、全部角色与 Skill 组合的加载、三阶段依赖、非法覆盖、已触发的条件步骤、失败传播、跳过与重放。契约兼容测试核对生成 bundle、既有样例和历史固定摘要。上述测试记录策略和工程行为；作品正文、真实模型 Attempt、全文盲评和 RELEASE 按各书分别验收。

配置与 DAG 在同一事务内登记为受类型约束的工件，由作品和分支的两个选择引用绑定。首次绑定需当前管理授权和当前 WorldRef；相同配置重试返回原引用，竞争提交的不同配置会被拒绝。角色任务自身不能重绑定作品配置。`tests/integration/test_p6_profile_binding.py` 在 PostgreSQL 17 上验证五个预设由新的连接池和内核实例读回，以及权限拒绝、头部变化、竞争绑定及事务中断恢复。

## 篇幅与成稿来源

原始委托中的篇幅区间在作品分支内单独绑定。全文评审登记与最终内部发布均核对这一绑定。汉字数按有序正文的 Unicode 汉字逐字计数，包含扩展区汉字和“〇”，排除标点、数字及外部元数据。章节数来自已冻结的章节 ID 和按卷接续的检查点；一个章节中的多个场景只能计作一章。篇幅仅为预设建议时，记录实测数据；明确提交上下限时，两个边界均包含在合格范围内。

每个场景核对已接受的写手任务、代际、上下文、已结算 Provider Attempt、模型结果与实际正文字节。来自初始灵感入口的作品，另验设计任务与独立设计审核的真实调用及原始篇幅。不含真实模型来源的宿主导入稿和 Fixture 草稿不能作为正式 P6 成稿验收。手动建立计划的工程项目可保留其真实来源分类。
