四个已验证的数据库共用同一实例。随后真正停止并重启 PostgreSQL，确认旧 PID 文件消失、服务器启动时间变化和数据库系统标识一致；再次逐表比较四库数据、授权、触发器模式和已提交请求。NF 对端使用确定性夹具，外部模型请求为零。
