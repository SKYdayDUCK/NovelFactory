## Reproduction and observations

A fresh PG17 cluster ran the three tests cited in `path-examples.json`. All three passed. `capture_paths.py` whitelists only the public request body, path bindings, outcome, label and source test. It never records headers. `empty-claim.json` captures the observed HTTP 200 null. A separate Workshop/NF exercise captured five successful MCP responses covering two submissions and NO_ATTEMPT, UNKNOWN and SETTLED lookups; failed/refused calls from the original matrix are preserved separately.

`check_surface.py` instantiates the registered FastAPI routing table without reaching a database, compares it to the NF, installation and Workshop registries, validates all 98 input examples and checks the section names and per-method registration and example links in both reference pages. The first post-revision run matched 34 NF, 34 Workshop, two installation and 28 HTTP entries, and all 392 point links. Results include the individual public-file digests. This check complements but cannot infer the authorization and retry semantics from schema alone. The independent source review above covers those behaviors.


## Final independent recheck

**PASS for the reviewed technical documentation.** T01–T08 are closed in both languages. The reviewer independently verified the promotion correction using a fresh PostgreSQL 17.11 grant pair: READ returned VIEW_DENIED, BRANCH returned a comparison. The final reference requires BRANCH on both branches and PROMOTE on the ready repair. Initial acceptance requires READ and ACCEPT, replay of an already committed receipt requires READ. The guarded error list now distinguishes approval, history, branch ancestry and footprint failures from the legacy-only schema error.

The six published path examples exactly match the recaptured invocation data. Removing a binding, using an invalid UUID or adding an unknown binding each triggered the exporter. Runtime registration, request validation, bilingual section coverage and every registration/example point link all passed on the final tree.
