# API reference audit

Two independent extractions compared the NF, Workshop and delegation registries and FastAPI routes. Both found 34 role/author NF tools, 34 Workshop tools, two NF installation tools and 28 HTTP routes. All 98 appear once in each language and have registered input, access, retry, domain error, result and example information. The two references share sample files, with their source tests. Inputs and all six path-bound UUID examples were checked; schemaless output variants were traced through handlers and contrasted with captured results.

The audit caught the empty claim returning JSON null, nullable delegation receipt fields, known-only cost totals, REPAIR-only promotion, caller-key versus server-UUID confusion, and five POST routes requiring path UUIDs. A fresh PG17 run captured all six route examples in one call each with matching path bindings. Four Workshop handlers and four NF application returns are labeled separately from the other fixture calls. 20 HTTP examples ran through the transport and eight reconstruct the documented route request around the observed application return.
