## 修复前可复现的五个错误接受

通用命令为 `python scripts/with_postgres.py --log-dir <pg目录> --migrate -- python -m pytest -q tests/integration/test_s9_query_coverage.py --junitxml=<结果路径>`。五项均在正式 Kernel.accept 处得到“DID NOT RAISE DomainError”。这些变化发生在独立于候选转粮命令的世界状态上。

| pytest 参数 | 原生查询与检验 |
| --- | --- |
| implicit_edge_closure | 阅读北门→剑→铁匠的两条图边；DESTROY_ITEM 自动关闭持有关系；新世界同一查询只返回一条。 |
| scoped_timeline | 一名角色的 scope_id 定位北门，ADVANCE_SCOPE 只推进北门。角色时间线 coverage 从 PARTIAL 变为 COMPLETE。 |
| visited_graph_frontier | 图的种子北门和末端铁匠已覆盖，推进中间节点剑的前沿，实际图查询的 coverage 从 PARTIAL 变为 COMPLETE。 |
| existing_text | 通过既有 Kernel.put_artifact 制作 TEXT 并将版本真实绑定为消息正文。另一任务获得授权并读取原文，此后同一载体的真实性发生变化。 |
| spaced_version_reference | 通过 MessageSourceService 得到版本，将合法、有空白的 JSON 引用绑定为正文。另一任务授权读同一内容，之后真实性变化。 |
