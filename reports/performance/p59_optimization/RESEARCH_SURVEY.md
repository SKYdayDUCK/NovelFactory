| Group scope upserts into one PostgreSQL command. ON CONFLICT DO UPDATE gives each proposed row an insert-or-update outcome and rejects attempts to affect one row twice. | KernelRepository.bump at src/novel_factory/infrastructure/repository.py:75 and Kernel._accept_transaction. Four unique scope writes plus one read in all seven samples. [PostgreSQL INSERT](https://www.postgresql.org/docs/17/sql-insert.html) · [SQLAlchemy PostgreSQL DML](https://docs.sqlalchemy.org/en/20/dialects/postgresql.html#insert-on-conflict-upsert) | Deduplicate and sort before applying the set in the same transaction. Preserve same target conflict index, lock order and returned map. Compare increment/rollback, retries and concurrent writers. Small localized change. |
| Cover a lookup with INCLUDE columns after inspecting buffer reads, and project only the columns needed by a consumer. The visibility map affects index-only scans. | Query plan for branch scope map in raw/write-baseline.json and KernelRepository.scope_map. A wider index incurs extra writes. Compare heap fetches, buffers and WAL at realistic history size before adding an index. Low implementation cost, unproved benefit. |

Score 1/2/4 tenants' queue delay and completion separately. Implementing a new allocator also requires restart-proof quotas. Keep a research hypothesis. |
