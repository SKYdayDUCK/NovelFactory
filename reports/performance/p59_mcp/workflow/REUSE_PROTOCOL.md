# Workshop installation connection reuse experiment

Preregistered before the timing run. The comparison targets the Workshop worker's existing NF delegation transport. A opens a fresh process and session for each request. B keeps one pair for one installation within one CLI batch. Both list the authorized tools before every call and rely on NF's transaction-time authorization. Benchmark two distinct books/installations with genuine preprovisioned receipts, 4 reads per book per arm, concurrent books and serial requests per installation, sequence A/B/B/A. Include setup, handshake, discovery, execution and retirement in wall time from before the first request to both workers' completion. Cold generation setup is outside the timed loop. Report raw rows and per-call send-to-reply p50/p95/p99, including the first cold call in B. No model sends. Require identical full receipts, zero unexpected errors, elapsed-time throughput ratio >=1.10 and P95/P99 <=1.10 times A in both adjacent pairs. Small N limits any tail SLA conclusion. An additional untimed live grant-revocation check on a reused binding must retain the installation's actual restrictions. Session setup failure is handled by the existing per-operation outcome logic; no transport-level retry of a write is added. This method measures closed-loop delegation receipt reads under two workers. It does not measure all books' creative tasks or sustained remote capacity.
