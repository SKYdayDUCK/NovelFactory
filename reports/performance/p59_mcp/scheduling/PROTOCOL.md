# 主机调度与路由回放预登记

冻结源 `9364b154941bfbbe95a57fee5ceb600f5219fa5b`。此项使用标准库离散事件回放。整数 tick 为假定 1 ms 服务需求，不计作真实 MCP、数据库、模型或 OS 容量。四个虚拟远程副本各至多一个活动槽。可信主机预设每个绑定的合格副本集，客户端不能选择身份、作用域或任意路由目标。原 stdio 一条绑定一个子进程时合格集合只有一个元素。

预设三种开环输入：稀疏、持续热点、同刻突发；三种种子 17/29/53。服务需求含短读、较长上下文组装、续租和长模型等待，多个作品有不同到达率；每个副本有 24 个最大等待项。各配对在同种子、同一到达轨迹依 A/B/B/A 顺序隔离重放。固定假设下重复结果必须逐项相同；这项重复不是独立硬件抽样。

独立变量为按副本 FIFO、按作品/类型的 WFQ 或 DRR、DRR 加等待老化、对热点请求有界并保留控制流空间、随积压调节全局活跃槽、轮询/最少在途/二选一、模型等待释放后的继续执行和混合配置。主指标分别为每作品/类别的逻辑完成数、续租在 20 tick 内完成比例、有效完成数/含排空耗时、已完成请求计划至返回 P95/P99、队列及活动/等待峰值、排空时长。接收但超时的续租归入过期，分开报告准入拒绝。调度器无持久状态，回放不访问数据库或模型。每条记录存计划、入队、首次运行、完成或拒绝时刻。

如机制样本显示某策略只是扩大等待、完成率或 P99 恶化，保留作反例。所有策略都需在真实 MCP 和服务端授权路径通过独立正逆序验收后才有生产采用资格。回放的吞吐数字单位为条/模拟时间，不得用以签署 MCP 容量。
