# 独立进程容量补测

预注册仪表化阶梯限定 4 GiB RSS。各进程 RSS 会重复计入共享页，达到该预算无法回答机器还能维持多少真实 Host。为此追加本项，维持原实验的结果与保护条件。该项单独运行，继续使用独立迁移库、锁定 SDK 和真实单任务角色凭证。

服务器按未插桩的生产命令逐个启动。每个进程必须完成 initialize 与完整四项角色发现，累计至多 200 个。在 2/10/50/200 档及最后一次观测中，所有已启动会话并发执行四种读操作，逐个对账。启动前观察当前系统可用内存，减去此前测得最大 USS 后仍须剩余 1 GiB，避免实验导致同机其他任务被系统终止。观测 Linux 实际 RSS/USS/PSS、可用内存、PID、SQL 连接数和各作品完成数。数据库容量以服务实际返回为准，允许已有连接按生产空闲规则收缩。记录条件触发时最后成功完成验证的绑定数，其他共享作业和内核页回收影响这个数量。本补测不执行候选采纳判定。
