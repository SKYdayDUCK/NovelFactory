# HERA 候选验收

**发布判定为 Draft，性能验收未通过。** 在真实 PostgreSQL 17.11、MCP SDK 1.29.0、REST、stdio、Redis 和模拟 Provider 上核实了若干业务能力。普通全量进度读取、同预算的千角色突发完成时间及重索引下的读隔离均未达到开发前冻结的目标。历史 AT-30 保留每秒 950 次正确完成的原门槛和 NOT_MET 记录。[预登记](BASELINE.md) · [历史报告](../p59_runtime/RESULTS.md) · [Issue #13](https://github.com/SKYdayDUCK/NovelFactory/issues/13)

## 发布范围

全局数据库连接数的配置核算必须包括所有 API、执行进程、stdio 子进程、维护和 LISTEN。全局任务准入与模型/索引槽由 PostgreSQL 裁定。认证速率和 HTTP 内存队列按进程限制；新建副本需要重新核对部署连接清单。DB_READ_HEAVY、DB_WRITE、MAINTENANCE、NOTIFICATION 各有现有的处理入口和局部限额，尚缺统一的跨进程分类执行预留。项目身份延用既有 work/branch 和 task/generation/attempt，新 ID 适配没有覆盖所有历史工作流。多作品读写、正式世界接受、ContextBundle、历史/冻结查询及租约存在各自的回归；同一组固定权重的混合负载没有把全部十四类操作都放在一起。5000 个逻辑任务的验证截至 PG READY，没有对该组逐项执行模型。

## 混合读取的实际请求分母

6 个规模乘 5 种入口比例共验证 43,750/43,750 次读取，MCP 与 REST 各 21,875 次。每个单元由 20 个独立且有授权的活动客户端发请求，四条 PG 连接和两个业务槽。5000 请求单元的 0% / 50% / 100% MCP 分别取得 79.29 / 46.71 / 28.57 次正确读取每秒，P95 为 393 / 586 / 1084 ms。单元内的累计请求数、不同身份数、模型并发数分别统计。实验没有采样实时已建立 TCP socket 总数。[六规模五配比完整矩阵](MIXED_READ_MATRIX.md)

另外一组 1000 个不同任务所有者在同一时刻发起状态查询，500 个远程 MCP 与 500 个 REST 客户端均正确，排空 25.11 秒，从同时放行到响应的 P95 为 23.92 秒。其轻量任务元数据与单角色完整读取使用不同契约。[千客户端状态读取](FAST_PATH.md)

对于请求种类，两个角色、两个冻结版本与作品历史、进度、同权限批读、创建/取消重试在同一次 TCP 负载内交错。182 次操作中 154 次按授权成功，28 次预期拒绝均正确。另列真实租约续期、正式世界接受、模型等待、审核、唤醒和 Workshop 委托的对应测试。[14 类操作与证据对照](MIXED_OPERATIONS.md)


## 验证和治理

* Linux 最终产品代码的完整回归覆盖 1,066 个不同测试，其中 1,063 项通过，仅跳过 3 个 Windows 专用测试；另有 17 个子测试通过。包括在独立的两个 PG17 集群上运行的 S6 全流程和曾在开发工作树失败的用例。具体重跑与原失败均保留。[Linux 全套原始结果](raw/linux-final-suite.xml.gz) · [兼容性及 Workshop 结果](COMPATIBILITY.md)
* Workshop 常规套件 123 项通过、1 项受早期 Docker 环境限制跳过。后续两个独立数据库集群加原生 Redis 8.0.2 的完整恢复专项 6/6 通过，实际终止了专用 Redis 进程并从 SQL 重建收件。模型均为模拟，双向委托各验证 18 个 token 的合法结算。[故障证据](FAILURE_RECOVERY.md)
* 独立组件复核修正了 REST/MCP 恢复范围、跨入口启动绑定快照、stdio 错误兼容、队列资源配置与旧索引 Worker 限额。公开接口导出与来自真实入口的示例均已复核，110/110。[代码复核](../../code_review/hera/REVIEW.md) · [CI 与修复](CI.md)
* 保持 Draft。Windows 原生和远端 Linux 结果以具体候选提交的作业结论为准，早期通过、失败与后续候选分开登记于 CI 记录；完整 Windows 全套与自动合并均不作为本报告的已通过项目。PR #36 的 Checks 显示最新提交状态。[CI 门禁](https://github.com/SKYdayDUCK/NovelFactory/pull/36/checks)
