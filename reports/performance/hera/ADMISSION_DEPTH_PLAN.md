# Durable admission cost by backlog depth

Use fresh migrated PG 17 databases, two works, 16 distinct authorized owners, identical TaskSpec shape, 4 connections and zero overflow. Depth checkpoints: 0, 50, 200, 500, 1000, 2000 and 5000. Insert 5,000 tasks with the ordinary committed Kernel.create_task call in each arm, admission disabled (reference) and admission enabled (candidate). No external network or model. At each checkpoint run 8 new authorized probes per arm in interleaved A/B/B/A blocks; record the real per-transaction create+commit time before cancelling each probe and restoring live depth. Preserve raw input identities, states, results, table and index size snapshots, process RSS, per-backend RSS, source revision and EXPLAIN ANALYZE/BUFFERS for the enabled occupancy query. Clean/active DB byte growth covers tables and indexes; probes leave a small measured terminal history in both arms. Report bulk mixed-protocol population trials separately. Compare baseline and candidate, and assess additional query buffering or indexing only against measured bottlenecks. Exact counters across historical tasks, trusted restores and changing role maps require transactional correctness before adoption.
