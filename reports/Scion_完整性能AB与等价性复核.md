# Scion 完整性能 A/B 与等价性复核

## 基线、样本与比较口径

接管时的应用基线是 e757419，冻结的世界内核是 2c28acb。A 为接管版本、原三组实验开关关闭。B 开 worker 与 review 两个 B1 元数据读取点；C 只开 B2；D 为 B+C；E 只开 B3 与 lazy；F 只开 worker，等同本轮未显式配置的集成默认值。普通固定查询的 B1 单独在 S2 测量。静态 schema 与重复父版本建证另作独立同输入配对。因主混合 HTTP 不投递派生 outbox，F 在该业务里不应计入 worker 微基准的收益。

每对从同一 PG17.11 模板克隆数据库与对象目录，保持 fsync、synchronous_commit、种子、业务图、角色权限、进程/池预算和 CPU 亲和性。每个原始记录有源文件、夹具和测量器指纹。36 个串行精确样本覆盖两种世界、六臂各三次；相同请求字节、事件选择和最终状态摘要逐项验证。真实 HTTP 让服务正常签发证书和回执，后续请求中的服务端随机标识可以不同。1000/s 为原开放读发送目标。超时、未发送、限流、幂等重试沿用原判据。

主矩阵候选测量源码 01a5ba5 在 S4 收紧静态引用回退之前冻结。两个有差异的应用文件、每个样本的源摘要以及从 S4 恢复测量树的补丁都已归档。A–F 没有启用静态引用。共享机器的后台时序随运行变化。单个 HTTP 配对只作为该轮观测；同输入、同 CPU 与反序复测分别列出。精确请求中的 JSONB 字节来自实际 codec。HTTP 模式记录解码次数与时间，未安装精确字节计量。HTTP 的 PG 进程树 CPU 采样在此宿主会漏掉后台进程，数据库总 CPU 无可报告值；S2 的实际连接后端 CPU、HTTP 应用 CPU、SQL 次数与连接峰值可复核。[恢复测量源码](../evidence/scion_round2/s5/reproduction/source_map.json)

## 正确性与回归

冻结原始源码在独立 PG17 上产出六个场景的 oracle。最终比对 10 种配置，每种配置核对 35 张表，每臂跨场景共 7,238 行、210 个成功接口响应和 27 个领域错误。所有受比较的业务 JSON、权限切面、选择与状态摘要、审批和回执保持一致。沿用原差分的数据库管理时间戳比较存在性，契约内时间字段精确比较。专项另覆盖冷进程、驱逐、并发和故障注入。
